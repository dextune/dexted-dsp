# Dexted DSP 산업용 전환 마스터 플랜

**문서 버전:** 1.0 / 2026-10-08  
**기준 소스:** `0a2c1c4e87fa868c166953e9527a3ac721fe01c3`의 `main`  
**문서 성격:** 구현·시험·출시의 실행 계획입니다. 제시한 목표를 이미 달성했다는 보고서가 아닙니다.

## 최종 GOAL

> 실제 제품의 최종 배포 IIR/SOS 계수에 대해, 허용 범위 안에서는 검증 가능한 전 대역 이득·안정성 판정을 내리고, 판정할 수 없으면 안전하게 배포를 차단하며, 그 판단과 도구의 버전을 제3자가 재현할 수 있는 **오프라인 필터 배포 품질 게이트**를 만듭니다.

첫 정식 버전은 SciPy/python-control을 대체하는 범용 DSP 엔진이나 실시간 안전 인증 제품을 목표로 하지 않습니다. 기존 설계·처리 도구에 Dexted의 수학적 검사를 추가하는 제품을 목표로 합니다. 평균 자체평가 9.5점 대신 **필수 출시 게이트 전부 통과**를 사용합니다.

## 반드시 구분할 세 가지 검증

| 검증 축 | 시험 대상 | 발견하려는 문제 | 이 시험만으로 주장할 수 없는 것 |
|---|---|---|---|
| A. 계수·수학 | 최종 f32/f64 SOS 계수, 임계값, 인증서 | 거짓 인증, 경계값·불안정성·위조 증명 | 실제 CPU의 매 연산 반올림 안전성 |
| B. 장시간 신호 | 여러 개의 30분~24시간 입력과 실제 처리기 | 상태 초기화, 블록 경계, 장기 오차·비정상값 | 모든 가능한 입력과 주파수에 대한 증명 |
| C. 운영 내구성 | 검증 작업자·큐·파일·배포 파이프라인 | 메모리 누수, 타임아웃, 재시작, 잘못된 배포 | 제품 전체의 기능 안전성 인증 |

긴 파일 재생으로 A를 대신하지 않고, A의 인증으로 B/C를 생략하지 않습니다.

## 기계 판독 가능한 부속 자료

[장시간 24건 매니페스트](manifests/long-signals-v1.json), [계수 데이터 계획](manifests/coefficient-corpus-v1.json), [외부 자료 등록부](manifests/external-sources-v1.json), [승인 목표](manifests/qualification-gates-v1.json)를 제공합니다.

[스트리밍 생성·검사 도구](tooling/longrun.py)는 전체 자료를 메모리에 올리지 않습니다. 기본 `smoke`는 2초로 명시되며, `pilot`는 서로 다른 **6건 × 30분 = 3시간**, `qualification`은 **24건 = 76시간**의 신호를 실제 샘플 단위로 생성·처리합니다. 76시간짜리 신호를 빠르게 처리한 것은 76시간 벽시계 내구 시험이 아닙니다.

이번 도구는 SciPy 참조 처리기를 사용한 시험 기반입니다. `--with-dexted`를 명시한 실행만 설치된 Dexted를 호출합니다. 그 경우에도 계수 인증과 실수 연산 신호 처리 결과는 별도 주장입니다. 실제 현장 녹음·제품 계수는 아직 확보되지 않았으며 합성 자료로 대체 표기하지 않습니다.

## 완료 상태 표기 규칙

`PLANNED` → `IMPLEMENTED` → `EXECUTED` → `EXTERNALLY_REPRODUCED` → `APPROVED`를 구별합니다. 검증 실패·권한 미확보·아직 실행하지 않은 검사는 별도 상태로 남깁니다. 이 계획의 주요 산업용 목표는 기본적으로 `PLANNED`입니다. 이번 도구의 실행 결과는 [별도 증거](evidence/README.md)에만 기록합니다.
